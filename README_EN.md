# MERSENE GAHENAX

This repository is dedicated to deterministic Mersenne-number experimentation and Lucas–Lehmer verification.

## Scope

- PRP search and deterministic Lucas–Lehmer verification.
- Checkpoint, residue, fault-injection and orchestration infrastructure.
- Mersenne telemetry and integrity audits.

Riemann-zero datasets, spectral analyses, reports and the Mersenne–Riemann POC were migrated to [Gahenax/Riemman-Zero](https://github.com/Gahenax/Riemman-Zero). They are intentionally not duplicated here.

## Scientific limits

Internal metrics and simulation telemetry are not primality certificates. Only reproducible arithmetic results with independent verification may be reported as certifications.
